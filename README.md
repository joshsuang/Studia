Studia

A clean, focused study dashboard built to make studying easier.

Studia combines a Pomodoro timer, tasks, statistics, and customizable study settings into one simple workspace.

Features

* Pomodoro Timer
    * Focus sessions
    * Short breaks
    * Long breaks
    * Customizable durations
    * Session tracking
* Study Dashboard
    * Today’s study overview
    * Focus sessions
    * Study time
    * Progress and streaks
* Tasks
    * Create study tasks
    * Mark tasks as complete
    * Keep track of what still needs to be done
* Statistics
    * Daily and weekly study time
    * Completed focus sessions
    * Study activity
* Customization
    * Timer settings
    * Notifications
    * Appearance preferences
* Responsive
    * Desktop
    * Tablet
    * Mobile

Design

Studia is designed around a simple idea:

Less distraction. More focus.

The interface uses a clean, minimal design with smooth interactions and a focus on making the important information easy to see.

Tech Stack

* React
* TypeScript
* Tailwind CSS
* Vite

Getting Started

Clone the repository:

git clone https://github.com/YOUR_USERNAME/studia.git
cd studia

Install dependencies:

npm install

Start the development server:

npm run dev

Then open the local URL shown in your terminal.
